🎯 USO NO OBS STUDIO (RECOMENDADO)
═══════════════════════════════════════════════════════════════════════

1. Abra o OBS Studio

2. Adicione uma nova fonte:
   • Clique no "+" em Fontes
   • Selecione "Navegador"
   • Dê um nome (ex: "Awards Overlay")

3. Configure a fonte:
   
   OPÇÃO A - Arquivo Local (Recomendado):
   ────────────────────────────────────────
   • Marque: ☑ "Local file" (Arquivo Local)
   • Clique em "Procurar"
   • Selecione: overlay.html
   • Largura: 400
   • Altura: 600
   


4. Configurações extras (recomendadas):
   • ☑ Desativar o encerramento da fonte quando não visível
   • ☑ Atualizar navegador quando a cena ficar ativa

5. Clique em OK

6. Posicione o overlay na tela:
   • Arraste para o canto inferior esquerdo
   • Redimensione se necessário

7. PRONTO! Os awards aparecem automaticamente! 🎉

🌐 TESTE NO NAVEGADOR
═══════════════════════════════════════════════════════════════════════

🎨 PERSONALIZAÇÃO DE CORES
═══════════════════════════════════════════════════════════════════════

Para mudar as cores, abra overlay.html e edite as linhas 11-28:

  --card-font-color: #ffffff;           → Cor do texto (branco)
  --card-border-color: rgba(...);        → Cor da borda
  --card-tag-color: #ffd100;            → Cor da barra lateral (amarelo)
  --card-bg: rgba(0, 0, 0, 0.45);       → Fundo do card (preto transparente)
  --border-radius: 12px;                → Arredondamento das bordas

EXEMPLOS DE CORES:
  • Vermelho: #ff0000
  • Verde: #00ff00
  • Azul: #0066ff
  • Roxo: #9b59b6
  • Laranja: #ff6600
  • Rosa: #ff1493

🐛 SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

❌ NADA APARECE NO NAVEGADOR/OBS
   
   Solução:
   → Abra o Console (F12 no navegador)
   → Veja a aba "Console" para mensagens de erro
   → Verifique sua conexão com internet
   → Aguarde até 15 segundos (primeira carga + primeira atualização)
   → Se você NÃO TEM AWARDS, o overlay fica invisível (normal!)
   → Verifique se DV e API_KEY estão corretos (linhas 156-157)

❌ "ERRO AO CARREGAR AWARDS"
   
   Solução:
   → Verifique conexão com internet
   → Confirme que o site megamu.net está online
   → Tente atualizar a página (F5)
   → Verifique se DV e KEY estão corretos

❌ OVERLAY NÃO APARECE NO OBS
   
   Solução:
   → Certifique-se que marcou "Local file"
   → Verifique se o caminho do arquivo está correto
   → Tente clicar com botão direito na fonte > "Atualizar"
   → Aumente a largura/altura da fonte no OBS

❌ OVERLAY APARECE CORTADO NO OBS
   
   Solução:
   → Aumente a altura da fonte (ex: 800 pixels)
   → Ajuste o tamanho da fonte arrastando os cantos
   → Verifique se tem muitos awards (ocupa mais espaço)

📊 FORMATO DOS DADOS
═══════════════════════════════════════════════════════════════════════

A API retorna os awards neste formato:

{
  "result": 1,
  "awards": [
    {
      "name": "Wings of Angel (14d)",
      "id": "612800",
      "date": "2025-10-25 21:14:27"
    },
    {
      "name": "Steel of Heaven",
      "id": "612776",
      "date": "2025-10-25 20:14:38"
    }
  ]
}

O overlay mostra o campo "name" de cada award.
